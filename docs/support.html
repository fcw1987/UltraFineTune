Support

Adjust system playback using presets and tone controls. Start with the build guide and usage guide.

Download and open

Get the 1.0.0 app and checksum on GitHub Releases. Extract the ZIP and read INSTALL.md. Requires Apple silicon and macOS 14.2+. The app is not Developer ID signed or notarized; if blocked, review Apple’s app-specific opening guidance, or build the reviewed source.

Silent or waiting for audio?

Stop tuning and confirm ordinary playback works. Select the same stereo physical output in macOS Sound Settings and the app. Confirm system audio capture permission in Privacy & Security, then quit and reopen after permission changes. Some protected or directly routed audio may not be captured.

Report a bug or request a feature

Open a GitHub issue with macOS and app version, output model and connection, steps to reproduce, expected result, and observed status. Review diagnostics for device identifiers and local paths before sharing. Do not upload recordings or credentials.

Security reports

Use private vulnerability reporting for sensitive reports.

Compatibility and validation

Stable version 1.0.0 build 3 is available for Apple silicon (arm64). The app is ad hoc signed, not Developer ID signed or notarized. Live audio quality, latency, permission and recovery acceptance remain pending. Read the full limits.
